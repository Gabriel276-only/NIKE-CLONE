# Portfólio de E-commerce

Este projeto é um exemplo de **landing page** para um portfólio de e-commerce. Ele foi desenvolvido para mostrar uma interface moderna e interativa, com foco em animações suaves, responsividade e performance otimizada.

## Tecnologias Utilizadas
- **HTML5**: Estrutura do conteúdo da página.
- **CSS3**: Estilização e animações.
- **JavaScript**: Funcionalidades interativas, incluindo a animação de efeitos.
- **Flexbox**: Para o layout flexível e responsivo.
- **Media Queries**: Para tornar o site adaptável a diferentes dispositivos.
- **Lazy Loading**: Para otimizar o carregamento das imagens.

## Funcionalidades
- **Menu Mega Responsivo**: Um menu com várias opções de navegação que se adapta conforme o tamanho da tela.
- **Animações**: Transições suaves usando `@keyframes` para melhorar a interação do usuário com o site.
- **Design Responsivo**: A interface foi construída para funcionar perfeitamente em dispositivos móveis, tablets e desktops.
- **Otimização de Performance**: Lazy loading de imagens e minimização dos arquivos CSS e JavaScript.
